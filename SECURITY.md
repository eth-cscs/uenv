# Security Policy

## Supported Versions

Support for vulnerability reporting and patching started with v10 of uenv.
We will accept vulnerability reports for the versions tabulated below:

| Version | Supported          |
| ------- | ------------------ |
| 10      | :white_check_mark: |
| <  10   | :x:                |

## Reporting a Vulnerability

### Submitting Vulnerabilities

Submit security vulnerabilities directly on the uenv GitHub repository: https://github.com/eth-cscs/uenv/security

### Responses

We will acknowledge receipt of the issue as quickly as possible, and endeavor to accept or reject it within 30 days of reporting.

We will fix the vulnerability and patch within 90 days.

* fixes will be back-ported as patch releases to all supported MAJOR.MINOR versions to which they are relevant.

### AI Report Policy

Reports clearly generated using AI will be treated with skepticism, but not rejected out of hand.
If using AI to find and report an issue, we appreciate using AI to also provide a concrete solution to to the issue.
